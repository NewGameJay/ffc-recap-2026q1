How the attribution works (in plain English)

HubSpot tags every paid customer with two attribution data points: a first touch (the marketing channel that brought them to the site for the first time) and a last touch (the channel they used right before converting). These are the same fields that drive the FFC HubSpot dashboard.

  • First touch answers "how did we acquire this person?" — useful for understanding which channels are bringing in new audience.
  • Last touch answers "which channel closed them?" — useful for understanding which channels are converting.
  • A deal counts in this report as MH-attributable if either the first touch OR last touch is a marketing channel MH-1 operates. We don't double-count — each deal counts once.

Meta-attributed revenue (the $43,244) is a separate model — it's Meta's own platform attribution using its 7-day click / 1-day view window, captured server-side via the pixel. This is largely complementary to HubSpot (e.g., FFD ticket purchases that ran through a different flow than the membership deals HubSpot tracks).

The April attribution-recovery line ($28,515) is an estimate, not a captured number. It applies February+March's blended Meta ROAS to April spend to recover what the partial pixel didn't capture — methodology and three independent estimation methods are detailed in Appendix A2.
